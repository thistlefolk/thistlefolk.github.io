English

This policy describes the Windows app Offgrid Desk: Solar + Diesel Sizer (version 1.0) distributed through the Microsoft Store, published by Thistle Folk.

What Thistle Folk does not collect

Thistle Folk does not create accounts for this app, does not show advertising in the app, and does not include analytics or its own cloud storage. Sizing calculations run on your computer. We do not receive your project, your coordinates, or your device location unless you choose to email them to us. We do not sell customer lists, because the app does not send that information to us.

The Microsoft Store processes the one-time purchase. Thistle Folk does not receive your payment card number through the app.

Information stored on your device

The app can save your wizard inputs and progress (including site coordinates, equipment settings, and any appliance names you type) and your language choice in local storage on this device, so you can continue later. Optional live sunlight results are kept in memory for the current session and are not written to that local store.

You can remove the saved estimate with Clear saved estimate. You can also delete any project files you exported. Uninstalling the app is expected to remove the app’s local storage.

Project files

If you use Save project, the file is written where you choose on this computer. A project file includes the coordinates and equipment settings you entered. Names you typed for individual loads are omitted from the exported file. If you had run a live sunlight lookup, the saved sunlight values may be included. Review a file before you share it, and delete copies you no longer need.

Optional device location

If you choose Use my location, Windows will ask for location permission so the app can fill in latitude and longitude. If you decline, you can type coordinates or pick a bundled reference city. Getting a location fix does not, by itself, contact NASA POWER or Thistle Folk.

Optional live sunlight lookup (NASA POWER)

You can work entirely offline using bundled sunlight data for reference cities. Only if you choose the live sunlight lookup does the app send the site latitude and longitude, together with fixed climate query parameters, directly to NASA’s POWER service (power.larc.nasa.gov) to fetch solar climatology. That request is not sent to Thistle Folk. We have no affiliation with NASA.

Parties who may receive information

NASA, and only if you choose the live sunlight lookup, receives the coordinates and fixed query parameters described above. Microsoft processes Store purchases and provides Windows and the WebView2 runtime; this policy does not cover Microsoft’s own services. Thistle Folk receives only what you send to hello@thistlefolk.com (for example, a question or a file you attach), and uses it to reply to you. The app does not otherwise transmit your project or location to third parties.

Your controls

Do not grant location permission, and do not start a live sunlight lookup, if you do not want those features used. Use Clear saved estimate to remove saved wizard inputs from this device. Delete exported project files you no longer need. Uninstall the app when you want it and its local data removed from this device. Email hello@thistlefolk.com if you have a privacy question or need help understanding a file you already shared. We reply within 7 days.

Children

This app is a general technical tool. It is not directed at children and does not seek personal information from children.

Changes

If a later version starts collecting or transmitting additional personal information, we will update this policy and the Microsoft Store listing before that version is published.

Contact

hello@thistlefolk.com. We reply within 7 days.

Preliminary screening only, not for construction design. A qualified local installer must verify the system. Local electrical codes apply.

简体中文

本政策适用于通过微软商店分发的 Windows 应用 Offgrid Desk: Solar + Diesel Sizer（1.0 版），发布者为 Thistle Folk。

Thistle Folk 不收集哪些信息

本应用不设账户，没有应用内广告，也不包含统计分析或由我们提供的云存储。选型计算在你的电脑上完成。除非你主动把项目、坐标或位置信息发到我们的邮箱，否则 Thistle Folk 不会收到这些内容。应用不会把这类信息发送给我们，因此我们也不会出售客户名单。

一次性购买由微软商店处理。Thistle Folk 不会通过应用收到你的支付卡号。

保存在本机的信息

应用可以把向导中的输入和进度（包括站点坐标、设备参数，以及你填写的用电设备名称）和语言选择保存在本机本地存储中，方便下次继续。可选的在线日照查询结果只保留在当前会话的内存里，不会写入上述本地存储。

可用“清除已保存的估算”删除已保存的内容，也可自行删除导出的项目文件。卸载应用预期会同时删除该应用的本地存储。

项目文件

使用“保存项目”时，文件会写到你在本机选择的位置。项目文件包含你输入的坐标和设备参数，你为单项负荷填写的名称不会写入导出文件。如果做过在线日照查询，查到的日照数值可能会一并保存。分享前请自行检查，不再需要的副本请删除。

可选的设备定位

如果你选择“使用我的位置”，Windows 会请求定位权限，以便填入经纬度。若你拒绝，仍可手动输入坐标，或选择内置参考城市。仅获取定位本身，并不会访问 NASA POWER，也不会把位置发送给 Thistle Folk。

可选的在线日照查询（NASA POWER）

你可以使用参考城市的内置日照数据，完全离线工作。只有在你主动选择在线日照查询时，应用才会把站点经纬度和固定的气候查询参数，直接发送给 NASA 的 POWER 服务（power.larc.nasa.gov）以获取日照气候数据。该请求不会发送给 Thistle Folk。我们与 NASA 没有任何隶属或合作关系。

可能接收信息的各方

NASA 仅在你选择在线日照查询时，接收上文所述的坐标和固定查询参数。Microsoft 处理商店购买，并提供 Windows 和 WebView2 运行时；微软自身服务不在本政策范围内。Thistle Folk 只会收到你发到 hello@thistlefolk.com 的内容（例如咨询或你主动附上的文件），用于回复你。除此之外，应用不会把你的项目或位置传输给第三方。

你可以使用的控制

如果不希望使用相关功能，请不要授予定位权限，也不要启动在线日照查询。使用“清除已保存的估算”删除本机保存的向导输入。删除不再需要的导出项目文件。如需从本机移除本应用及其本地数据，请卸载应用。隐私问题，或对你已经分享的文件有疑问，请发信 hello@thistlefolk.com。我们将在 7 天内回复。

变更

如果后续版本开始收集或传输更多个人信息，我们会在该版本发布前更新本政策和微软商店页面。
