English简体中文

English

Thistle Folk (“we”) publishes Island Grid Dispatcher, an offline educational simulation. This policy describes what the Windows app does with information on your computer. It applies to the Microsoft Store package identified as ThistleFolk.IslandGridDispatcher (Store ID 9N0S3WBT7J21).

The app does not collect personal information

The app does not ask you to create an account or to enter your name, email address, payment details, or any other personal information. We do not include advertising, analytics, crash-reporting, or other telemetry in the app. We do not sell or share customer information, because the app does not send information to us.

The app runs offline during normal use

Game files are included in the package. A small host program shows them in a Microsoft Edge WebView2 window, reading them from the install folder through an in-process handler at https://app.localhost/. That address is not a website on the public internet. The host blocks navigation away from this packaged content and does not declare an internet-client capability.

During normal play the app does not make network requests and does not contact Thistle Folk or any other service.

One optional, user-started exception

The app needs the Microsoft Edge WebView2 Runtime. Windows 11 includes this runtime. Some Windows 10 PCs do not. If the runtime is missing, the host shows a message and, only if you choose OK, opens Microsoft’s official WebView2 download page in your default browser:

https://developer.microsoft.com/microsoft-edge/webview2/

That step is started by you. The game itself does not download the runtime in the background and does not send us a notice.

Information stored only on your device

  • Language preference. If you switch between English and Simplified Chinese, the app may save that choice in the WebView2 profile as a local preference named dispatcher-language. Nothing else is written to this storage.
  • WebView2 profile. The host keeps a WebView2 user-data folder under your Windows profile, typically %LOCALAPPDATA%\ThistleFolk.IslandGridDispatcher\WebView2. This is ordinary browser engine data (for example cache) used only on your PC. We cannot read it.

Uninstalling the app removes the package. You can also delete the folder above if it remains after uninstall. There is no account for us to delete, because we do not hold your data.

Children

The app is a general educational simulation and is not directed at children. It does not collect personal information from anyone, including children.

Changes

If a later version of the app starts collecting, storing, or transmitting personal information, we will update this policy and the Store listing before that version is published. The date at the top of this policy is the effective date of the current text.

Contact

Questions about this policy or the app: hello@thistlefolk.com

简体中文

Thistle Folk（“我们”）发行《孤网调度员》（Island Grid Dispatcher），这是一款离线教学仿真。本政策说明该 Windows 应用如何处理你电脑上的信息，适用于 Microsoft Store 包 ThistleFolk.IslandGridDispatcher（Store ID 9N0S3WBT7J21）。

应用不收集个人信息

应用不会要求你注册账户，也不会要求填写姓名、电子邮箱、付款信息或其他个人信息。应用内没有广告、分析、崩溃报告或其他遥测。我们不会出售或共享用户信息，因为应用不会向我们发送信息。

正常使用时离线运行

游戏文件包含在安装包内。一个小型宿主程序在 Microsoft Edge WebView2 窗口中显示这些文件，通过进程内处理程序从安装目录读取，地址为 https://app.localhost/。这不是互联网上的网站。宿主会阻止离开该打包内容的导航，并且未声明 internetClient 能力。

正常游玩时，应用不会发起网络请求，也不会联系 Thistle Folk 或任何其他服务。

一项由用户主动发起的例外

本应用需要 Microsoft Edge WebView2 运行时。Windows 11 已预装；部分 Windows 10 电脑可能没有。如果缺少该运行时，宿主会弹出说明；只有在你选择“确定”后，才会用默认浏览器打开微软官方下载页：

https://developer.microsoft.com/microsoft-edge/webview2/

这一步由你主动发起。游戏本身不会在后台下载运行时，也不会向我们发送通知。

仅保存在本机的信息

  • 语言偏好。 如果你在 English 和简体中文之间切换，应用可能把该选择保存在 WebView2 配置中，键名为 dispatcher-language。此外不会向该存储写入其他内容。
  • WebView2 配置目录。 宿主会在你的 Windows 用户目录下保留 WebView2 用户数据，通常位于 %LOCALAPPDATA%\ThistleFolk.IslandGridDispatcher\WebView2。这是浏览器引擎在本机使用的常规数据（例如缓存），我们无法读取。

卸载应用会移除安装包。如果卸载后上述文件夹仍在，也可以自行删除。我们没有需要删除的账户，因为我们并不保存你的数据。

儿童

本应用是面向一般使用者的教学仿真，不以儿童为对象。它不会向任何人（包括儿童）收集个人信息。

变更

如果后续版本开始收集、存储或传输个人信息，我们会在该版本发布前更新本政策和商店商品页。文首日期为现行文本的生效日期。
